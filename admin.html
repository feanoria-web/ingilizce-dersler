Ders bilgileri

Seviye

En fazla 45 MB. CSS, JavaScript ve görselleri içinde bulunan tek bir HTML dosyası seçin. Ayrı dosyalara bağlı derslerin bu dosyaları da GitHub'a yüklenmelidir.

Dosyanın GitHub'daki konumu:

1. Hazır dosyayı indir ↓ 2. GitHub'a yükle ↗

Üç adımda yayında

  1. Ders dosyasını hazırlayınBu sayfa ders bilgilerini dosyanıza ekler. İşlem kendi tarayıcınızda yapılır.
  2. İndirin ve GitHub'a yükleyinİndirdiğiniz dosyayı açılan yükleme sayfasına sürükleyin. GitHub hesabınızın projeye yazma izni olmalıdır.
  3. “Commit changes” ile kaydedinKaydın ardından GitHub Actions ders listesini günceller ve siteyi yayımlar. İşlem birkaç dakika sürebilir.

Dosyayı hazırlamak veya indirmek siteyi yayımlamaz. Dersin görünmesi için GitHub'a yükleyip değişikliği kaydetmeniz gerekir. Bu panel GitHub şifresi veya erişim anahtarı istemez.
